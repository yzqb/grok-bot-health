What data is accessed

With the owner's consent, {{APP_NAME}} reads the owner's own Google Health data through the Google Health API using read-only scopes: activity and fitness (e.g. steps), health metrics (e.g. resting heart rate, HRV, SpO2), sleep, profile and device settings (last sync time). It never writes or deletes any data.

How it is used

Only to show the owner summaries of their own data and to remind the owner to move after long sitting.

Storage and sharing

Data and the authorization token are stored only on the owner's private cloud computer, readable only by the owner. Nothing is published, sold, shared with third parties, or used for advertising. This website contains no health data.

{{APP_NAME}}'s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.
